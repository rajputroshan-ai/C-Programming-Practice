Student Record System in C

About

A beginner-level C program that stores and displays a student's roll number, name, and marks using a structure.

Concepts Used

- Structures ("struct")
- Variables and data types
- Input and output using "scanf()" and "printf()"
- Character array for a name

Features

- Takes a student's roll number as input
- Accepts a name containing spaces
- Takes marks as input
- Displays the entered student record

Testing

- Tested with a roll number, a multi-word name, and marks.
- Verified that the entered details are displayed correctly.

File

"student_record_system.c"

Learning Goal

To practise C structures and basic input/output operations.
